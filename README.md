# Portfolio — Cristian Eduardo Alba

Portfolio personal, construido con **React + Vite**. Muestra mis proyectos, stack y forma de contacto.

🔗 Sitio en vivo: https://cristalba22.github.io/portfolio/

## Stack

- React 19 + Vite
- Three.js (fondo animado del hero)
- CSS puro (sin frameworks de UI), con animaciones e íconos de marca embebidos como SVG

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

Genera la carpeta `dist/` lista para deployar en cualquier hosting estático.
